# FAQs as Administrator. Hub Management

### What are the main responsibilities of a Hub administrator?
A Hub Administrator manages the entire FLAME platform, overseeing infrastructure, organizations, authentication, node management, registry, project oversight, and user support.
For detailed responsibilities, refer to [Components in Hub](https://docs.privateaim.net/getting-started/components.html).

### How do I manage Realms?
Realms are organizational namespaces managed by Hub administrators. Key actions include creating, providing initial realms, and monitoring activities.
For more details, refer to [Realm Management](https://docs.privateaim.net/guide/admin/realms.html).

### How do I manage users and roles?
Manage users and roles through the **Admin area**. View, add, edit, assign roles/permissions, and delete users or roles as needed.
For detailed steps, see [User Management](https://docs.privateaim.net/guide/admin/users.html) and [Role Management](https://docs.privateaim.net/guide/admin/roles.html).

### How do I set up and manage identity providers?
Identity providers authenticate users externally. 

Set up by navigating to Admin area → Auth → Identity Providers, adding configurations like Client ID, Secret, and endpoints. 
For detailed setup, refer to [Identity Providers](https://docs.privateaim.net/guide/admin/identity-providers.html).

### How do I view and assign permissions?
View and assign permissions in the Admin area under Permissions and Roles tabs. Assign roles to users to grant specific permissions. 
For more information, see [Permissions and Roles](https://docs.privateaim.net/guide/admin/permissions.html).

### How do I review and approve analyses?
Hub administrators review analysis code for safety and protocol adherence. 
Navigate to Home → Analyses → Incoming, download, review, and approve or reject analyses. 
For detailed steps, refer to [Analysis Review](https://docs.privateaim.net/guide/admin/analysis-review.html).

### How do I register and manage local nodes?
Register nodes in the Admin area under General → Nodes. 
Fill in required information, generate credentials, and deploy locally. 
Manage node settings and credentials as needed. 
For more details, see [Node Registration](https://docs.privateaim.net/guide/deployment/node-registration.html) in the deployment part and [Node Management](https://docs.privateaim.net/guide/admin/node-management.html).
